# GrowFast – Digital Marketing Agency Website

GrowFast is a digital marketing agency website created using HTML, CSS, and JavaScript. It demonstrates how a digital marketing agency can present its services, pricing plans, client feedback, and contact information through a simple website.

## Features

- **Home Section:** Introduction to the GrowFast digital marketing agency.
- **Services Section:** SEO, Social Media Marketing, Email Marketing, and Paid Ads.
- **Pricing Section:** Basic, Standard, and Premium plans.
- **Results Section:** Example marketing results and growth statistics.
- **Reviews Section:** Client testimonials and ratings.
- **Contact Section:** Contact information and an enquiry form.
- **Form Validation:** Checks name, email, and 10-digit mobile number using JavaScript.
- **Smooth Navigation:** Navigation links take users to different sections of the website.

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, layouts, colours, and design
- JavaScript – Contact form validation
- Google Chrome – Testing and preview

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the website.

## Contact Form

The contact form includes basic JavaScript validation for:
- Name
- Email address
- 10-digit mobile number

**Note:** The form currently performs client-side validation only. It does not send or store submitted information.

## Project Purpose

This project was developed as a practical exercise to understand HTML structure, CSS styling, JavaScript functions, form validation, and website navigation.
